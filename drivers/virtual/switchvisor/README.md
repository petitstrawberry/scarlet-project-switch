# Scarlet Switchvisor guest module

This crate provides the guest control device. The device requires the Switchvisor control overlay and a monitor that implements the control interface.

Imported from [Switchvisor 164f3f1](https://github.com/petitstrawberry/switchvisor/tree/164f3f1bce0f3613013ddf06cf2024a3ddb6da84/scarlet). Licensed under GPL-2.0-only.
